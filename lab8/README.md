This lab implements the K-Nearest Neighbors (KNN) algorithm to perform classification on a given dataset. The workflow includes loading and exploring the data, preprocessing and standardizing features, splitting the dataset into training and testing sets, training a KNN model, and evaluating its performance using a confusion matrix and classification report. The project also identifies the optimal value of K by analyzing the error rate across different values. The implementation is done in Python using libraries such as NumPy, Pandas, Matplotlib, Seaborn, and Scikit-learn.
