This lab demonstrates the implementation of a Support Vector Machine (SVM) classifier using Python and Scikit-learn on the Iris dataset. The notebook includes data exploration, visualization using Seaborn and Matplotlib, preprocessing, splitting the dataset into training and testing sets, training an SVM model, evaluating performance with confusion matrices and classification reports, and improving model accuracy through hyperparameter tuning using GridSearchCV. The lab is designed as a practical introduction to supervised machine learning and classification techniques.
