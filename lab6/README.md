Ecommerce Customer Spending Prediction

Overview:
This Lab uses ML(Linear Regression) to predict how much a customer spends yearly based on their behavior on an e-commerce platform.
The dataset contains customer information such as session length, time spent on app/website, and membership duration.

The dataset used is:
Ecommerce Customers.csv

Features:
Avg. Session Length
Time on App
Time on Website
Length of Membership
Target:
Yearly Amount Spent

The lab starts by loading and exploring the dataset using Pandas, followed by selecting relevant features and splitting the data into training and testing sets. A Linear Regression model is then trained on the training data, used to make predictions on the test data, and finally evaluated using metrics such as MAE, MSE, RMSE, and R² to assess its performance.
